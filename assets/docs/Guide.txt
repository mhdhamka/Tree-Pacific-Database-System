
## Installation Guide

### 1. Clone Repository

Download the project to your local web server environment (e.g., XAMPP `htdocs`):

```bash

git clone --branch improved-version --single-branch https://github.com/mhdhamka/Tree-Pacific-Database-System.git

cd Tree-Pacific-Database-System

2. Install PHP DependenciesThe vendor folder is excluded from this repository via .gitignore to keep the codebase lightweight and follow standard PHP development practices.Ensure Composer is installed on your environment:Bashcomposer --version
Rebuild the vendor/ directory and generate the autoloader by running:Bashcomposer install
This will automatically restore:Plaintextvendor/
├── dompdf/
├── phpoffice/
├── composer/
└── autoload.php

❓ TroubleshootingMissing vendor/autoload.php ErrorIf you run the application and see:PlaintextWarning: require(vendor/autoload.php): failed to open stream: No such file or directory
Run composer in the project root to generate the missing folder:Bashcomposer install
Database Connection FailedEnsure MySQL service is running.Confirm the database name in src/config/db.php is strictly set to tree.Required PHP ExtensionsEnsure the following PHP extensions are enabled in your php.ini file:mysqlimbstringgdzipxml⚙️ Development Note on vendor/The vendor/ folder is explicitly listed in .gitignore. Only composer.json and composer.lock are tracked in version control. Running composer install will recreate the exact dependency environment on any machine at any time.
